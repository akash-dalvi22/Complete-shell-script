# Complete Shell Scripting Guide

Welcome to the Complete Shell Scripting repository — a practical and beginner-friendly collection of shell script examples covering the fundamentals of Bash scripting.

This repository is designed to help learners understand shell scripting step by step, from the basics of writing scripts to more advanced concepts like loops, operators, and functions.

## 🚀 What You Will Learn

This repo covers:
- Basic shell scripting concepts
- Variables and environment variables
- Arithmetic and logical operators
- Conditional statements and comparisons
- Loops and control flow
- Functions in shell scripting

## ▶️ How to Use

1. Open the desired day folder.
2. Read the script files.
3. Run them using Bash.
4. Practice and modify them to strengthen your understanding.

Example:
```bash
bash scriptname.sh
```
